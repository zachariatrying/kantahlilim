# KanTahlilim

e-Nabız kan tahlili sonuçlarını sunucuya yüklemeden %100 cihaz içinde okuyan, referans aralığı çubuğunda gösteren ve doktor muayenesi öncesi sorular hazırlayan KVKK uyumlu sağlık takipçisi.

## 🌐 Web'de Kullan
- **Canlı Adres:** https://zachariatrying.github.io/kantahlilim/
- **Telefona PWA Olarak Ekleme:** Tarayıcı menüsünden **Ana Ekrana Ekle** ile uygulama gibi açabilirsiniz.

## 📱 Android APK İndir & Kur
1. [Build Android APK & Play AAB](https://github.com/zachariatrying/kantahlilim/actions/workflows/android-apk.yml) sayfasına gidin.
2. En üstteki yeşil iş akışı koşusuna tıklayın ve alttaki **Artifacts** bölümünden **`kantahlilim-debug-apk`** dosyasını indirin.
3. ZIP'ten `app-debug.apk` dosyasını çıkarıp Android cihazınıza kurun.

## 🛠️ Yerel Geliştirme
```bash
npm install
npm run dev
npm run build
npx cap sync
```
