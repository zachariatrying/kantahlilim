# KanTahlilim — Cihaz İçi Laboratuvar Tahlil & Trend Okuyucu

**Canlı Web:** https://zachariatrying.github.io/kantahlilim/  
**Paket Kimliği:** `com.kantahlilim.app`

Hastane ve özel laboratuvar PDF tahlil raporlarını **%100 cihaz içi** (`pdfjs-dist`) okuyup Ferritin, B12, D Vitamini, TSH, HbA1c, AST/ALT, Kreatinin gibi 18 temel parametreyi referans ölçeğinde görselleştiren bağımsız kişisel sağlık takip aracı. (Resmî kamu kurumu uygulaması değildir.)
